mini-claude-code

终端里的轻量级 AI 编程助手 —— 读懂需求，自主调用工具完成代码任务。

v1.0.1 · 开源教学项目

🤔 这是什么？

mini-claude-code 是一个极简的 Code Agent 教学示例，灵感来自 Claude Code。 它运行在终端中，通过与大语言模型的多轮对话理解你的需求，自主调用工具完成任务。

核心逻辑仅约 200 行代码，无臃肿依赖、无复杂抽象层。 非常适合用来理解 Agent 的工作原理和 Tool Calling 设计模式。

🚀 快速开始

确保已安装 Bun 运行时，并在项目根目录创建 .env 文件配置 API Key：

$ bun install
安装依赖
$ bun src/index.ts
启动交互式 Agent
$ cat .env
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxx
DEEPSEEK_API_BASE_URL=https://api.deepseek.com
环境变量配置（以 DeepSeek 为例）

💡 支持 DeepSeek / OpenAI 兼容接口，修改 provider.ts 即可切换。

⚡ 核心功能

📖

读取文件

分段读取大文件，带行号预览，不撑爆上下文

✍️

写入文件

创建新文件或完整覆盖已有文件

🔧

局部编辑

精确匹配字符串实现局部替换，避免全量重写

🔍

搜索内容

在项目中搜索文本或符号，快速定位代码

💻

执行命令

运行 Shell 命令并获取输出，安全拦截危险操作

🌐

抓取网页

获取在线文档或 API 响应，转为 Markdown

🧰 可用工具

Agent 在循环中可自主调用以下工具：

read_file

读取文件内容（支持 offset/limit）

write_file

创建或覆盖文件

edit_file

精确替换文件中的内容

search

搜索项目中的文本或符号

list_files

浏览项目目录结构

bash

执行 Shell 命令

web_fetch

抓取网页并转为 Markdown

🏗️ 项目架构

代码结构清晰，每个模块职责单一：

src/
  ├─ agent/  # Agent 核心循环
  │  ├─ loop.ts       # 模型调用 ↔ 工具回填 → 步骤输出
  │  ├─ context.ts    # 上下文压缩
  │  ├─ session.ts    # 会话保存 / 恢复
  │  ├─ prompt.ts      # 系统提示词组装
  │  └─ provider.ts   # 模型提供商配置
  ├─ tools/   # 工具定义 & 注册
  │  ├─ index.ts      # 工具注册入口
  │  ├─ bash.ts        # Shell 执行
  │  ├─ edit-file.ts   # 局部编辑
  │  ├─ list-files.ts  # 目录浏览
  │  ├─ read-file.ts   # 文件读取
  │  ├─ search.ts      # 文本搜索
  │  ├─ web-fetch.ts  # 网页抓取
  │  └─ write-file.ts  # 文件写入
  ├─ index.ts          # 入口
  └─ utils/      # 辅助函数
       ├─ confirm.ts     # 用户确认交互
       ├─ safety.ts      # 命令安全检测
       └─ truncate.ts    # 输出截断

bin/
  └─ minicc.cjs        # CLI 入口
tests/                  # 单元测试

🛠️ 技术栈

Bun 运行时 TypeScript AI SDK DeepSeek OpenAI 兼容 Zod 校验

📦 构建 & 全局安装

$ bun run build
构建到 dist/index.js
$ bun run build:binary
编译为单文件二进制 dist/minicc
$ bun run link:global
全局安装，终端可直接使用 minicc 命令
