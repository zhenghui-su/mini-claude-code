mini-claude-code

一个运行在本地终端的轻量 Code Agent —— 能读写文件、执行命令、访问网络，帮你完成编程和开发任务。

v0.1.0 · 教学用途

🤔 何为 mini-claude-code？

这是一个精简版 Code Agent，灵感来自 Claude Code。 它通过多轮对话理解你的需求，自主调用工具来读写文件、执行 Shell 命令、 抓取网页，最终完成编程任务。

与 Claude Code 不同的是，mini-claude-code 完全开源、 代码量极小（~200 行核心逻辑），非常适合用来学习 Agent 的工作原理、 理解工具调用（Tool Calling）的设计模式。

⚡ 核心功能

📖

读取文件

支持分段读取大文件，带行号预览，不撑爆上下文

✍️

写入文件

创建新文件或完整覆盖已有文件

🔧

局部编辑

通过精确匹配字符串实现局部替换，避免全量重写

💻

执行命令

运行 Shell 命令，危险操作会暂停等待确认

🌐

抓取网页

将网页内容转为 Markdown，方便查阅文档

💬

多轮对话

维持对话历史，支持 /reset 重置、上下文压缩

🛠️ 技术栈

Bun 运行时 TypeScript Vercel AI SDK DeepSeek / OpenAI Zod 校验

使用 Bun 作为运行时（比 Node.js 更快）， 通过 Vercel AI SDK 接入大语言模型， 默认支持 DeepSeek 和 OpenAI 兼容接口，Zod 负责工具参数的校验。

🚀 快速上手

# 1. 安装依赖 bun install
# 2. 配置环境变量（.env） DEEPSEEK_API_KEY=sk-xxxxxxxx DEEPSEEK_BASE_URL=https://api.deepseek.com
# 3. 启动 Agent bun start
进入交互式终端，即可开始对话

🎯 设计理念

mini-claude-code 是为学习而生的 Agent 教学示例。 它没有臃肿的依赖、没有复杂的抽象层，核心逻辑聚焦在 "Agent Loop — Tool Calling — Context Management" 这条主线上。

如果你想理解 LLM Agent 是如何工作的、想自己动手定制一个 Agent， 这个项目是最好的起点。
