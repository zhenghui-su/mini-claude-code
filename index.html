mini-claude-code

ReAct 范式下的终端 Code Agent —— Agent 循环、工具调用、分层上下文管理，
用最少的代码展现 AI Agent 的核心机制。

v1.0.1 · 开源教学项目

🤔 这是什么？

mini-claude-code 是一个极简的 Code Agent 教学示例，灵感来自 Claude Code。 它运行在终端中，通过 LLM（默认 DeepSeek）驱动的 ReAct 循环理解你的需求，自主任意调用工具完成任务。

核心 Agent 循环仅约 160 行代码（src/agent/loop.ts）， 配合 Vercel AI SDK 的 generateText + tool 机制， 无需复杂框架即可实现"思考→行动→观察→思考"的完整闭环。

项目聚焦 四层设计： CLI 交互层 · Agent 循环层 · 工具注册层 · 安全/上下文辅助层。 每一层都能独立理解和替换，非常适合学习 Agent 架构。

🚀 快速开始

确保已安装 Bun 运行时，并在项目根目录创建 .env 文件配置 API Key：

$ bun install
安装依赖
$ bun src/index.ts
启动交互式 Agent
$ cat .env
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxx
DEEPSEEK_API_BASE_URL=https://api.deepseek.com
环境变量配置（以 DeepSeek 为例）

💡 支持 DeepSeek / OpenAI 兼容接口，修改 src/agent/provider.ts 即可切换。

🧰 可用工具

Agent 在循环中可自主调用以下 7 个工具，覆盖读写、搜索、执行和网络四大权限：

list_files

浏览项目目录结构（支持递归深度 control）

search

全局搜索文本或符号（大小写不敏感）

read_file

读取文件内容（支持 offset/limit 分段）

write_file

创建新文件或完整覆盖已有文件

edit_file

精确匹配字符串实现局部替换

bash

执行 Shell 命令（含危险命令检测）

web_fetch

抓取网页并转为 Markdown

🔐 权限模型

每个工具按权限分类，方便控制 Agent 的能力边界：

权限说明涉及工具
read读取或搜索本地项目内容，不修改文件list_files search read_file
write创建、覆盖或局部修改文件write_file edit_file
execute执行 Shell 命令（危险命令需确认）bash
network访问网络资源web_fetch

⌨️ 交互命令

在对话中输入以下 slash 命令控制 Agent 行为：

/help
查看所有可用命令
/plan <任务描述>
本轮先让 Agent 制定执行计划，确认后再执行
/context
查看当前上下文状态（模型、token 用量、压缩信息）
/compact
立即压缩上下文，将历史消息汇总为摘要
/reset
清空当前会话历史，重新开始
/sessions
列出所有已保存的历史会话
/exit
退出程序

🔄 Agent 循环原理

完整的交互流程如下：

  1. 用户输入 → CLI 层解析 slash 命令或自然语言任务
  2. 组装提示词 → 将系统指令 + 上下文摘要 + 历史拼装发送给 LLM
  3. 模型推理 → LLM 决定是直接回答还是调用工具
  4. 工具执行 → SDK 自动解析参数、执行、将结果回填到消息中
  5. 继续循环 → LLM 结合工具结果继续推理，直到得到最终答案
  6. 保存会话 → 每轮结束后自动保存历史，支持 minicc resume 恢复

上下文超过 102k tokens（上限 128k 的 80%）时自动压缩， 将历史多条消息合并为一段摘要，配合工作记忆和用户约束形成三层分层上下文。

🏗️ 项目架构

代码结构清晰，每个模块职责单一：

src/
  ├─ cli/         # 终端交互层
  │  ├─ app.ts          # 主循环：命令分发、多轮输入、HUD 渲染
  │  ├─ format.ts       # 终端展示、时间/用量格式化
  │  ├─ help.ts          # 帮助与版本说明
  │  ├─ constants.ts     # 提示符与 slash 命令定义
  │  ├─ resume.ts        # 历史会话选择/恢复界面
  │  ├─ slash.ts         # slash 命令匹配与 tab 补全
  │  ├─ theme.ts         # 终端颜色主题
  │  └─ working-indicator.ts # 执行中动画
  ├─ agent/       # Agent 核心层
  │  ├─ loop.ts          # ReAct 循环：模型调用 ↔ 工具回填 ↔ 步骤输出
  │  ├─ context.ts      # 分层上下文、自动压缩、工作记忆
  │  ├─ session.ts      # 会话保存 / 恢复 / 旧格式迁移
  │  ├─ prompt.ts       # 系统提示词三段式组装
  │  ├─ provider.ts     # 模型提供商配置（DeepSeek / OpenAI）
  │  └─ system-prompt.ts # 静态核心指令
  ├─ tools/        # 工具定义 & 注册
  │  ├─ index.ts        # 工具注册表（Zod 参数校验）
  │  ├─ result.ts        # 统一工具返回结构
  │  ├─ bash.ts          # Shell 执行
  │  ├─ edit-file.ts    # 局部编辑
  │  ├─ list-files.ts   # 目录浏览
  │  ├─ read-file.ts    # 文件读取
  │  ├─ search.ts       # 文本搜索
  │  ├─ web-fetch.ts   # 网页抓取
  │  └─ write-file.ts  # 文件写入
  ├─ utils/        # 辅助层
  │  ├─ confirm.ts      # 用户确认交互
  │  ├─ safety.ts       # 路径安全检查 + 危险命令检测
  │  └─ truncate.ts     # 工具输出过长时自动截断
  └─ index.ts          # 入口：启动 CLI

bin/
  └─ minicc.cjs        # 全局命令行入口
tests/                  # 单元测试（context / session / tools / utils）

🛠️ 技术栈

Bun 运行时 TypeScript Vercel AI SDK DeepSeek OpenAI 兼容 Zod 校验 Chalk 配色

📦 构建 & 全局安装

$ bun run build
构建到 dist/index.js
$ bun run build:binary
编译为单文件二进制 dist/minicc
$ bun run link:global
全局安装，终端可直接使用 minicc 命令
$ minicc resume
恢复上次的对话历史继续工作
